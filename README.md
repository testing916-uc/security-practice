# CompTIA Security+ (SY0-701) Practice Quiz

This web app provides multiple-choice questions for the **CompTIA Security+ (SY0-701)** exam. It's designed to help users practice and test their knowledge in different domains of cybersecurity. The app is built using **React** and **Next.js**, with **Tailwind CSS** for styling.

## Features
- **Multiple Domains**: Questions are organized by Security+ exam topics.
- **Interactive Quiz**: Each question shows 4 options, highlights the correct answer, and provides an explanation.
- **Mobile-Friendly**: Fully responsive design for easy use on phones.
- **PDF Export (optional)**: You can extend the app to export answers to PDF.
